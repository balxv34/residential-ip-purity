## 高纯净度住宅IP的“纯净度”，到底在指什么

纯净度由三项指标决定：ISP属性、历史信誉、独享程度。平台风控看的不只是IP地址本身，还会检查ASN归属、ISP运营商信息和历史信誉值——机房IP的ASN显示"Hosting"，等于自带“我是代理”的标签；住宅IP显示"Residential"，ISP一栏是AT&T、Comcast这类真实运营商，平台会把它当成一个真实的家庭用户。

另外两个词也经常一起出现。**静态**指IP地址固定不变：账号注册、长期养号、广告后台登录都依赖稳定的网络身份，动态IP每换一次，账号就可能触发一次重新验证。**双ISP**指IP同时归属两个ISP运营商，在IP数据库里的信誉权重比普通住宅IP更高，对TikTok这类风控出了名严格的平台，数据普遍会更好一些。

独享是第三层保障。一个IP只卖给你一个人，就不存在上一任用户拿它群发、爬虫、批量注册留下的黑历史；共享池里的IP，恰恰是纯净度翻车的大头。
